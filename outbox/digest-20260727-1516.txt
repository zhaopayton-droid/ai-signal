Paper1 | Skill Self-Play: Pushing the Frontier of LLM Capability with Co-Evolving Skills · 2026-07-25 01:59 北京时间
Problem 问题：LLM 自我进化训练面临"任务多样性 vs 验证可靠性"的矛盾——限定环境的方法反馈精确但任务面窄,开放式自生成任务面广但缺乏可靠验证,易被误导性奖励污染训练。
Approach 方法：提出 Skill Self-Play(Skill-SP),由 proposer（出题）、solver（解题）、动态技能控制器组成的共同进化框架,以"技能"作为可验证执行与开放式探索之间的折中点,通过强化学习循环持续扩展技能库。
Result 结果：在工具使用与推理基准上,Skill-SP 持续拉高强基座模型的能力上限,并能显著扭转最初表现不佳模型的结果。

Paper2 | The Regression Tax: Decomposing Why Skills Help and Hurt LLM Agents · 2026-07-25 01:50 北京时间
Problem 问题：给 agent 加"技能"通常只看平均任务成功率的提升,却掩盖了技能也可能让 agent 变差这一代价。
Approach 方法：在近 6000 次运行、两个办公自动化基准、三种模型/框架组合上,对比有无技能的表现,区分"回归"(不加技能能做对、加了技能反而失败)与"持续失败"两类,并定位三种回归成因：技能描述的"渗透效应"、"grounding 位移"和"验证位移"。
Result 结果：表现最好的技能主要靠"更少回归"取胜,而非"更多增益";多数回归和持续失败可通过更好的 grounding 与验证来修复，评估技能应拆解净效应而非只看整体提升。
https://arxiv.org/abs/2607.22520v1

Paper3 | TRACE-ROUTER: Task-Consistent and Adaptive Online Routing for Agentic AI · 2026-07-25 00:29 北京时间
Problem 问题：企业级 AI 常用按调用路由模型以平衡成本与质量,但 agent 类长流程任务的质量只由最终任务结果决定,逐次路由无法把反馈正确归因到具体路由决策。

Problem 问题：人类习惯通过影子、剪影、倒影等身体的"投影抽象"来交流，而机器人目前基本只能靠自身的物理形态来表达。
Approach 方法：作者用一只 21 自由度的灵巧手（带柔顺软皮肤以减少漏光、获得连贯剪影）加一个可微分的"影子自我模型"，构建了能做动态影子表达的机器人系统；给定目标影子图像或视频，机器人通过对学到的自我模型做基于梯度的搜索来优化手部姿态，再经过考虑碰撞的仿真细化，得到物理上可行的动作，并引入表达区域目标、时间平滑正则化和关键帧优化来保留关键动作线索。
Result 结果：在模拟和实体实验中，演示了机器人用影子表演手语手势、手影游戏和动物动作模仿，为机器人通过"自身的投影抽象"进行交流和视觉叙事建立了一个框架。
