Paper1. Beyond Scores: Understanding LLM-as-a-Judge Mechanisms in Summarization Evaluation
2026-09-02 01:59 Beijing | https://arxiv.org/abs/2609.01604v1
Problem: LLM judges score summarization quality, but how they internally arrive at a rating is poorly understood. Approach: An eight-attack perturbation taxonomy across readability/adequacy dimensions, generating paired clean vs. corrupted summaries with controlled error intensity, to probe judge behavior mechanistically. Result: The paper reports mechanistic findings on how judges respond to specific, controlled corruption types (full results in the paper).
问题：LLM 作为评审对摘要质量打分，但其内部是如何得出评分的机制并不清楚。方法：构建覆盖可读性/充分性维度的八种"攻击"扰动分类法，生成受控错误强度的干净版与被破坏版摘要配对，机制性地探测评审模型的行为。结果：论文报告了评审模型对特定受控破坏类型的具体反应机制（完整结果见原文）。

Paper2. Efficient SWE Agent Benchmarking via Trajectory-Aware Evaluation
2026-09-02 01:59 Beijing | https://arxiv.org/abs/2609.01603v1
Problem: Full software-engineering agent benchmarks are expensive; existing subset-selection methods for cheaper evaluation are result-only and ignore how an agent actually solves a task. Approach: PTA-IRT, a Privileged Trajectory-Aware Item Response Theory framework that uses trajectory information, not just pass/fail, to estimate full-benchmark performance from a subset. Result: The paper presents this as a more sample-efficient way to estimate SWE-agent benchmark performance (details in paper).
问题：完整的软件工程 agent 基准评测成本高；现有的子集抽样评测方法只看结果（通过/失败），忽略了 agent 实际解题的过程。方法：提出 PTA-IRT——一种"特权轨迹感知"的项目反应理论框架，利用轨迹信息而非仅仅是通过/失败结果，从子集估计完整基准的表现。结果：论文提出这是一种更节省样本的 SWE agent 基准评测估计方法（细节见原文）。

Paper3. Adaptive Critical Token-Aware Retrieval for Repository-Level Code Generation
2026-09-02 01:59 Beijing | https://arxiv.org/abs/2609.01601v1
Problem: Repository-level code generation needs repo-specific context via RAG, but existing retrieval provides only task-level context without pinpointing which tokens actually matter. Approach: A retrieval method that explicitly identifies critical tokens to guide adaptive, more targeted context retrieval. Result: The paper reports improvements over task-level RAG baselines for repository-level code generation (specifics in paper).
问题：仓库级代码生成需要通过 RAG 获取仓库特定上下文，但现有检索方法只能提供任务级别的上下文，无法精确定位真正重要的 token。方法：提出一种能显式识别关键 token 的检索方法，以此引导更具针对性的自适应上下文检索。结果：论文报告相较任务级 RAG 基线在仓库级代码生成上有所提升（具体数据见原文）。

Paper4. CordisBench: Can Language Models Reason About Component Lifecycles in Dynamic Agent Harnesses?
2026-09-02 01:59 Beijing | https://arxiv.org/abs/2609.01600v1
Problem: Agent harnesses that let models modify their own execution software create a new reasoning burden — tracking how a local plugin change propagates through dependencies and cleanup. Approach: CordisBench, a 1,200-question benchmark combining a formal setting with programs run against Cordis, a runtime managing component dependencies/cleanup, testing whether models can identify affected components and predict resulting state. Result: A new benchmark for this specific lifecycle-reasoning capability (model results in paper).
问题：允许模型修改自身执行环境软件的 agent harness 带来了新的推理负担——需要追踪一次局部插件变更如何通过依赖关系和清理逻辑传导下去。方法：提出 CordisBench，一个包含 1200 道题目的基准，结合形式化设定与运行在 Cordis（一个管理组件依赖与清理的运行时）上的程序，测试模型能否识别受影响的组件并预测最终状态。结果：这是针对这一特定"生命周期推理"能力的新基准（具体模型表现见原文）。

Paper5. The Rise of Verbal Reinforcement Learning
2026-09-02 01:58 Beijing | https://arxiv.org/abs/2609.01597v1
Problem: Natural language is becoming a primary feedback channel for improving language agents, but the field lacks a unified account of this paradigm. Approach: The paper names this paradigm Verbal Reinforcement Learning (VRL) and organizes it along one axis — when in an agent's lifecycle verbal feedback takes effect and what it modifies — yielding three pillars. Result: A survey/framework paper offering the first unified account of VRL (pillars detailed in paper).
问题：自然语言正逐渐成为改进语言 agent 的主要反馈渠道，但该领域尚缺乏对这一范式的统一梳理。方法：论文将这一范式命名为"言语强化学习"（Verbal Reinforcement Learning, VRL），并沿"言语反馈在 agent 生命周期中何时生效、修改了什么"这一单一维度组织出三大支柱。结果：这是一篇对 VRL 进行首次统一梳理的综述/框架论文（三大支柱细节见原文）。

Paper6. Facet-0: A Robotic Foundation Model for Contact-Rich Precise Manipulation
2026-09-02 01:58 Beijing | https://arxiv.org/abs/2609.01596v1
Problem: Sub-millimeter-tolerance robotic assembly needs spatial precision, compliant interaction, and robustness to contact failures. Approach: Facet-0, a robotic foundation model that predicts and values the contact consequences of its actions, unifying multimodal representation learning with RL post-training around a joint action-wrench proposal aligned with vision-language semantics. Result: Presented as a foundation model for precise, contact-rich manipulation (performance details in paper).
问题：亚毫米级公差的机器人装配任务需要空间精度、柔顺交互能力，以及对接触失败的鲁棒性。方法：提出 Facet-0，一个能预测并评估自身动作接触后果的机器人基础模型，将多模态表征学习与强化学习后训练统一在一个与视觉-语言语义对齐的联合"动作-力矩（wrench）"提案框架下。结果：论文将其作为面向精密接触式操作的基础模型提出（具体表现见原文）。

Paper7. Mechanism Design for Alignment and Control
2026-09-02 01:57 Beijing | https://arxiv.org/abs/2609.01595v1
Problem: When an AI agent's alignment (preferences) and capabilities are unknown, mechanisms acting on our behalf must incentivize both honesty and obedience. Approach: A mechanism-design framework built on a one-sided imitation structure (capabilities can be concealed but not counterfeited), yielding a revelation principle and a characterization of implementable policies via nested cyclical monotonicity. Result: Theoretical conditions under which eliciting higher-order truthful behavior from such agents is possible (full characterization in paper).
问题：当一个 AI agent 的对齐程度（偏好）和能力都未知时，代表我们行事的机制设计必须同时激励其诚实与服从。方法：提出一个基于"单边模仿结构"（能力可以被隐藏但不能被伪造）的机制设计框架，得到一条揭示原理，并通过嵌套循环单调性刻画了可实现的策略集合。结果：给出了在何种条件下可以从此类 agent 中诱导出更高阶诚实行为的理论条件（完整刻画见原文）。

Paper8. StudentSim: Training LLM-based Student Simulators
2026-09-02 01:55 Beijing | https://arxiv.org/abs/2609.01591v1
Problem: AI tutors work best when adapted to individual students, but evidence on which guidance works for whom is sparse and costly to collect from real learners; existing student simulators either fit behavior poorly or role-play fluently without matching real competence patterns. Approach: StudentSim, an LLM-based student simulator meant to bridge state-tracking accuracy and LLM role-play fluency. Result: Proposed as a better proxy signal for tutoring research (evaluation details in paper).
问题：AI 家教在能适配每个学生时效果最好，但关于"什么样的引导对什么样的学生有效"的证据稀少且从真实学习者身上收集成本高；现有的学生模拟器要么行为拟合差，要么角色扮演流畅但不能匹配真实的能力模式。方法：提出 StudentSim，一个基于 LLM 的学生模拟器，试图兼顾状态追踪的准确性与 LLM 角色扮演的流畅性。结果：被提出作为家教研究中更好的代理信号（评估细节见原文）。

Paper9. The Structure of Quantization Damage in LLMs: Why the Next Bit Should Be Spent Globally
2026-09-02 01:53 Beijing | https://arxiv.org/abs/2609.01587v1
Problem: Post-training quantization (PTQ) accuracy loss is uneven across models and usually hand-tuned per model. Approach: Using causal mixed-precision intervention as ground truth (raising each layer to 8-bit in turn and measuring recovered accuracy) across 9 open-weight models in 4 architecture families, the paper tests three hypotheses about where quantization damage concentrates. Result: Findings on how to better allocate a small extra precision budget globally rather than per-layer (specific guidance in paper).
问题：训练后量化（PTQ）带来的精度损失在不同模型间并不均匀，通常需要针对每个模型单独调参。方法：以因果混合精度干预作为基准（依次将每一层提升到 8-bit 并测量恢复的精度），在 4 个架构家族共 9 个开放权重模型上，检验三种关于量化损伤集中位置的假设。结果：给出了如何在全局而非逐层分配额外精度预算的发现（具体建议见原文）。

Paper10. Closing Cost-Quality Gap in Document VLMs: Difficulty-Aware Data Curation and Quality-Adjusted Deployment Economics
