There were reasonable concerns about data centers 18ish months ago: water, taxes, jobs, electricity prices, the environment and what they would do to small towns. Well-structured data center projects have largely addressed these concerns today and we should be celebrating this.

【Paper1】Logos: An Agent Harness on a Cross-Process Bus · 2026-08-29 01:30 北京时间
https://arxiv.org/abs/2608.28553v1

Problem: Most agent frameworks run every plugin/capability inside one process sharing one context, so a single fault or crash brings down every co-resident agent session at once.
Approach: Building on a formal calculus of capability composition, the paper proves an agent doesn't need to live in one process, then builds Logos, a ROS-like harness where each plugin runs as its own process and the only shared state is an append-only transcript.

问题:大多数 agent 框架把所有插件/能力放在同一个进程、共享同一个上下文里运行,一旦出现故障就会导致所有同驻会话一起崩溃。

https://arxiv.org/abs/2608.28475v1

Problem: When a multi-agent system changes its team composition, its messages and final answers change too, so a simple end-to-end accuracy gap can't tell you whether a "routing" decision (who's on the team) actually caused a performance difference.
Approach: COVER is an evaluation contract that fixes the public information boundary, downstream pipeline, and a finite set of legal team choices in advance, then argues that running the union of each frozen policy's chosen teams is the minimal way to identify every pairwise policy comparison.

【Paper7】DARTS: Decoder-Aware Representation Tuning via Surgery for Model Merging · 2026-08-29 01:22 北京时间
https://arxiv.org/abs/2608.28547v1

Problem: Merging multiple fine-tuned LLMs into one multi-task model causes "representation bias" — systematic drift from each source model's hidden states — and unlike encoder models, decoder models have this bias compound across token positions because of causal attention, with some positions mattering far more than others.
Approach: DARTS (Decoder-Aware Representation Tuning via Surgery) uses an entropy-weighted L1 correction loss that focuses on high-entropy, decision-critical token positions, plus a lightweight per-position additive bias to capture position-dependent drift without adding many parameters.
Result: On code generation (HumanEval), math reasoning (GSM8K), and instruction following (AlpacaEval) with Llama-2-7B, DARTS significantly beats standard surgery-based correction while adding only about 0.1% extra parameters.
问题:把多个微调过的 LLM 合并成一个多任务模型会产生"表征偏差"——合并后模型的隐藏状态系统性地偏离每个原始模型;和 encoder 模型不同,decoder 模型由于因果注意力机制,这种偏差会随 token 位置累积,而且不同位置的重要性差别很大。
方法:DARTS(基于手术式修正的解码器感知表征调优)采用一种按熵加权的 L1 修正损失,重点纠正高熵、对生成结果影响最大的 token 位置,再配合一个轻量的按位置叠加偏置来捕捉位置相关的偏差,而不需要大幅增加参数。
