Paper1 | TokTier: Exact Stateful Tokenization for Agentic LLM Serving · 2026-08-01 01:56 北京时间
Problem: Agentic LLM serving re-tokenizes the full growing request text on every call because KV caching covers attention but not tokenization, and a short append can shift token boundaries near the end of the prior sequence; across two real agent ecosystems, tokenization alone reaches up to 64% of time-to-first-token. Approach: TokTier is a stateful tokenization service guaranteeing emitted token IDs always match full reference tokenization — re-tokenizing only a small window around appends after a stability check, or running exact GPU-based pre-tokenization and BPE for fresh requests, with a sampled shadow verifier checking live traffic. Result: Across 17 tokenizer families and 1.5×10^10 differential checks, zero divergence from reference tokenization; incremental repair is up to 437x faster than Hugging Face tokenization, and in vLLM median time-to-first-token drops 16-34% under bursty traffic.
问题:agentic LLM 服务在每次调用时都要重新对不断增长的请求文本做完整分词——因为 KV 缓存只覆盖 attention,不覆盖分词,而且短小的追加内容也可能改变序列末尾附近的 token 边界。在两个真实 agent 生态中,分词本身能占到首 token 时间(TTFT)最高64%。方法:TokTier 是一个有状态分词服务,保证输出的 token ID 始终与完整参考分词一致——对追加内容只重新分词一个小窗口并经稳定性校验后拼接,对全新请求则在 GPU 上做精确的预分词和 BPE,并用抽样影子校验器持续核对线上流量。结果:在17个分词器家族、1.5×10^10次差分校验中零偏差;增量修复比 Hugging Face 分词最高快437倍;在 vLLM 中,突发流量下首 token 时间中位数下降16%-34%。
