Paper1 · VBVR-Pro: A Scalable and Verifiable Suite for Native Visual Reasoning · 2026-08-27 01:59 北京时间
Problem: Progress on "native visual reasoning" — using image/video generation itself as the medium of reasoning, not just input/output — is bottlenecked by a lack of scalable training tasks, reliable feedback, and controlled comparisons across generative substrates.
Approach: VBVR-Pro provides 300 procedurally generated tasks plus deterministic, task-specific verifiable reward scorers (rather than VLM-as-judge), enabling controlled studies across 30+ image/video/interleaved generators and large-scale multi-task RL.
Result: Models trained on VBVR-Pro transfer strongly to seven external visual-reasoning benchmarks; video generation is strongest for tasks needing persistent spatiotemporal state tracking, while interleaved generation is a compute-efficient alternative, and the deterministic scorers give stronger post-RL performance than VLM-judge approaches.
问题:"原生视觉推理"(把图像/视频生成本身当作推理媒介,而不只是输入或输出)的进展一直受限于缺乏可扩展的训练任务、可靠反馈,以及跨生成模态的可控对比。
方法:VBVR-Pro 提供 300 个程序化生成的任务,以及确定性、任务专属的可验证奖励打分器(而非用 VLM 当裁判),支持在 30 多种图像/视频/交错生成器上做受控研究,并用于大规模多任务强化学习。
结果:在 VBVR-Pro 上训练的模型能很好地迁移到七个外部视觉推理基准;视频生成在需要持续追踪时空状态的任务上最强,交错生成则是计算效率更高的替代方案,确定性打分器比 VLM 裁判方式带来更强的 RL 后训练表现。
https://arxiv.org/abs/2608.26105v1

Paper2 · A Visual Dependence-Aware Framework for Multimodal Unsupervised Continual Post-Training · 2026-08-27 01:57 北京时间
Problem: Deployed multimodal LLMs need to keep learning from streaming unlabeled data, but existing unsupervised post-training methods optimize all target tokens uniformly, ignoring that tokens differ in how much they actually depend on the visual input — which turns out to matter for avoiding cross-modal forgetting.
Approach: The proposed VDA framework combines Visually Constrained Optimal Transport, which treats old-task visual-dependence distortion as an optimal-transport problem to prevent forgetting without letting visual reliance collapse into language bias, with Visually Modulated Adaptation, which uses that same visual-dependence heterogeneity to emphasize visually grounded new-task learning.
Result: Under the paper's new Multimodal Unsupervised Continual Post-Training setting, VDA is shown experimentally to maintain old-task stability while improving new-task plasticity, outperforming baselines that treat all tokens uniformly.
问题:已部署的多模态大模型需要持续从无标注的流式数据中学习,但现有的无监督后训练方法对所有目标 token 一视同仁地优化,忽略了不同 token 对视觉输入的依赖程度其实并不相同——而这一点恰恰关系到能否避免跨模态遗忘。
方法:论文提出的 VDA 框架结合了两部分:用最优传输(Visually Constrained Optimal Transport)刻画旧任务视觉依赖的结构性扭曲以缓解遗忘,同时防止视觉依赖退化为语言偏置;以及利用同一种视觉依赖异质性,强化新任务中"基于视觉"学习的 Visually Modulated Adaptation。
结果:在论文提出的多模态无监督持续后训练设定下,实验显示 VDA 在保持旧任务稳定性的同时提升了新任务的可塑性,优于对所有 token 一视同仁处理的基线方法。
https://arxiv.org/abs/2608.26095v1

Paper3 · TraceML: An Empirical Analysis of Human-Agent Planning in Machine Learning Development · 2026-08-27 01:50 北京时间
Problem: LLM agents write correct code for isolated problems but remain far weaker at autonomous, hours-long ML development, and outcome-only benchmarks record this gap without explaining its cause because they discard the development process behind the final submission.
Approach: TraceML pairs human and agent work on the same Kaggle competitions under one version-level schema — 4,465 human trajectories across 134 competitions, with 430 human and 207 agent trajectories directly paired on seven shared competitions — each version tagged with score, timestamp, action, intent, edit size, and score effect.
Result: Experts alternate between data work, validation, model changes, and ensembling, revisiting abandoned approaches, while agent scaffolds (Codex, MLEvolve) collapse into narrow loops that rarely pivot or reopen past work; a planning prompt distilled from human practice shifts behavior toward the human profile and raises scores, but only closes the part of the gap reducible to instructions.
问题:大模型 agent 能为孤立问题写出正确代码,但在长达数小时、需要自主决策的机器学习开发任务上明显更弱;仅看结果的基准测试记录了这一差距,却因为丢弃了通向最终提交的开发过程而无法解释其成因。
方法:TraceML 用同一套版本级 schema,把人类和 agent 在同一批 Kaggle 竞赛上的工作配对起来——134 个竞赛中的 4,465 条人类轨迹,其中 7 个竞赛上有 430 条人类轨迹与 207 条 agent 轨迹直接配对,每个版本都标注了分数、时间戳、动作、意图、修改幅度和分数影响。
结果:人类专家会在数据处理、验证、模型改动、集成之间来回切换,并重新捡起被搁置的思路;而 Codex、MLEvolve 等 agent 脚手架则陷入狭窄的循环,很少转向或重启此前放弃的方案;一段从人类实践中提炼出的规划提示词能把行为拉向人类模式并提升分数,但只弥合了能靠"指令"解决的那部分差距。
https://arxiv.org/abs/2608.26086v1

Paper4 · ICON Decomposition: Multivariate Concept-Level Explanations of Deep Representations for Model Auditing · 2026-08-27 01:47 北京时间
Problem: Concept-based methods for auditing whether a model relies on a spurious concept (e.g. a patient's sex, scanner settings) usually test each concept in isolation, which can mistake correlations between concepts for evidence that the model actually uses one of them.
Approach: ICON decomposition instead quantifies how much of a layer's variance each concept explains after accounting for all other supplied concepts and the outcome, giving a multivariate rather than isolated view of concept reliance.
Result: On synthetic data with known ground truth, ICON recovers concept importance more accurately than seven baseline methods; on skin-lesion and brain-imaging models it isolates the concepts a model genuinely relies on, quantifies representation unexplained by any supplied concept, and produces sparse explanations validated by retraining and out-of-distribution testing.
问题:用来审计模型是否依赖某个虚假概念(如病人性别、扫描仪设置)的概念级方法,通常是逐个概念孤立检验,这容易把概念之间的相关性误判为模型确实依赖该概念的证据。
方法:ICON decomposition 改为在控制住其他所有给定概念及结果变量之后,量化某个概念能解释某一层多少方差,从而给出多变量而非孤立的概念依赖度量。
结果:在已知真值的合成数据上,ICON 比七种基线方法更准确地还原概念重要性;在皮肤病灶和脑影像模型上,它能识别出模型真正依赖的概念、量化出无法被任何给定概念解释的表征部分,并给出经过重训练与分布外测试验证的稀疏解释。
https://arxiv.org/abs/2608.26083v1

Paper5 · SwarmWorld: Stigmergic technological evolution in societies of language-model agents · 2026-08-27 01:45 北京时间
Problem: It's unclear whether decentralized LLM agents — without assigned roles, predefined recipes, or direct conversation — can actually build functional technologies and outperform independent best-of-N search, since most multi-agent systems still rely on centralized workflows.
Approach: In SwarmWorld, initially homogeneous LLM agents explore a spatial environment, process resources, test materials, and write executable controllers, while a deterministic simulator (not the agents) judges whether constructed artifacts actually function under unseen disturbances, splitting cognition from consequence.
Result: Shared societies develop broader, more resilient technological portfolios than a strong isolated-search baseline, though isolated search stays competitive for producing the single strongest artifact; agents differentiate into exploration/construction/maintenance/coordination roles as the world matures, and most technology reuse happens through physical observation rather than communication.
