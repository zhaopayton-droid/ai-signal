Problem: Inference-time scaling improves LLM reasoning but usually needs repeated generation or external verification, which is costly. 问题:推理时扩展能提升 LLM 推理能力,但通常依赖重复生成或外部验证,成本很高。
Approach: CritICL treats smaller models' failure modes as reusable signal, turning them into critique-based in-context examples — a dynamic variant predicts input-specific failure modes, a static variant uses a global failure-mode profile. 方法:CritICL 把小模型的失败模式当作可复用的信号,转化为基于"批评"的上下文示例——动态版本按输入预测特定失败模式,静态版本使用全局失败模式画像。
Result: Outperforms standard in-context learning and matches or beats test-time scaling methods, with far fewer generations and lower token cost. 结果:效果优于标准上下文学习,并达到或超过测试时扩展方法的水平,同时生成次数和 token 成本显著更低。

Paper2 · WikiSkill: Compiling Agent Experience into Persistent Knowledge for Skill Evolution · 2026-08-28 01:59 北京时间
Problem: Agent skills learned from experience tend to stay scattered across optimization runs, limiting systematic reuse. 问题:agent 从经验中学到的技能往往分散在各次优化过程里,难以被系统性地复用。
Approach: WikiSkill co-evolves agent skills with a persistent wiki-style knowledge base, separating raw execution experience, accumulated knowledge, and executable skills, continuously consolidating experience into the wiki. 方法:WikiSkill 让 agent 技能与一个持久化的 wiki 式知识库共同演化,把原始执行经验、积累的知识和可执行技能分离开,并持续把经验沉淀进 wiki。
