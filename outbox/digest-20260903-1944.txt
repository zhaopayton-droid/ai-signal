Paper1. A Common Measure of Communication for Speech Brain-Computer Interfaces
2026-09-03 01:59 Beijing | https://arxiv.org/abs/2609.02887v1
Problem: Speech brain-computer interface (BCI) systems use different datasets and vocabularies, so reported scores are not comparable across systems. Approach: The authors derive open-vocabulary mutual information (OVMI), an information-theoretic measure of how much of a user's intended speech a decoder actually conveys relative to a reference word distribution. Result: OVMI exposes cases where accuracy/WER overstate real communication capability, and choosing a vocabulary to maximize OVMI yields up to 16.3% relative accuracy improvement across three speech domains.
问题：语音脑机接口（BCI）系统各自使用不同的数据集和词表，导致报告的分数无法跨系统比较。方法：作者提出开放词表互信息（OVMI），这是一种信息论指标，用于衡量解码器相对于参考词分布，实际传达了用户多少意图表达的信息。结果：OVMI 揭示了准确率/词错误率（WER）会高估实际沟通能力的情况，而以最大化 OVMI 为目标选择词表，在三个语音场景中可带来最高 16.3% 的相对准确率提升。

Paper2. Discriminative World Models for Web Agents
2026-09-03 01:59 Beijing | https://arxiv.org/abs/2609.02885v1
Problem: Web agents' world models are trained via supervised next-state prediction, but this objective is misaligned with the downstream ranker that needs predicted states to be discriminative across candidate actions. Approach: The authors introduce predicted-state matching, a training objective requiring predicted states to distinguish the true resulting state from alternative-action outcomes, trained on branching WebArena trajectories. Result: The approach outperforms supervised next-state world models on a held-out benchmark, improves PRM-style action ranking on WebPRMBench, and improves end-to-end task success on WebArena-Lite.
问题：网页 agent 的世界模型通过监督式"下一状态预测"训练，但这一目标与下游排序器的需求不一致——排序器需要预测状态能在候选动作之间做出区分。方法：作者提出"预测状态匹配"训练目标，要求预测状态能把真实结果状态与其他候选动作的结果区分开来，并在带分支的 WebArena 轨迹上进行训练。结果：该方法在留出测试基准上优于监督式下一状态世界模型，在 WebPRMBench 上提升了 PRM 式动作排序效果，并在 WebArena-Lite 上提升了端到端任务成功率。

Paper3. Graph Machine: Towards Better Pretraining via Edges
2026-09-03 01:56 Beijing | https://arxiv.org/abs/2609.02881v1
Problem: Sequence models must choose between fixed-size states (cheap but limited memory) and fully dense attention (large state but costly), without an efficient way to keep a large potential state while still routing to it sparsely. Approach: Graph Machine (GM) maintains an O(n)-sized state accessed via sparse, dynamic routing using differentiable "edges," and the authors replace 75% of Qwen3-0.6B's dense Transformer layers with GM sparse layers, pretraining from scratch on 15.7B tokens. Result: Retrieving just 2 of 4,096 tokens per KV head per sparse layer degrades loss only slightly, and retrieving 4 tokens marginally improves loss over the dense baseline.
问题：序列模型通常要在固定大小状态（便宜但记忆有限）和完全密集注意力（状态大但代价高）之间取舍，缺乏一种既能保留大规模潜在状态、又能稀疏路由访问的高效方式。方法：Graph Machine（GM）通过"边"这种可微分的、类似指针的机制维持一个 O(n) 大小的状态，并用稀疏动态路由访问；作者将 Qwen3-0.6B 中 75% 的密集 Transformer 层替换为 GM 稀疏层，并在 157 亿 token 上从头预训练。结果：每个稀疏层每个 KV 头只检索 4096 个 token 中的 2 个时，损失仅轻微下降；检索 4 个时，最好的模型损失甚至略优于密集基线。

Paper4. Towards Trustworthy Autonomous Robots: An Explainable AI-Based Decision Framework
2026-09-03 01:44 Beijing | https://arxiv.org/abs/2609.02861v1
Problem: Autonomous robots powered by deep learning are hard to audit after incidents because investigators cannot reconstruct why the system made a specific decision. Approach: TRACE (Transparent Reasoning Architecture for Credible Execution) organizes decision-making into four auditable layers — perception, belief reasoning, action synthesis, and execution verification — designed to work alongside CNN/transformer perception modules while preserving decision-level traceability. Result: On simulated warehouse robot navigation across 500 decision cycles, TRACE achieved 98.6% evidence traceability, 99.0% temporal continuity, and 98.1% decision reconstructability, outperforming post-hoc methods like LIME on reconstruction capability.
问题：由深度学习驱动的自主机器人在发生事故后很难被审计，因为调查人员无法还原系统做出某个具体决策的原因。方法：TRACE（可信执行透明推理架构）把决策过程组织为四个可审计层——感知、信念推理、动作生成、执行验证——设计上可与 CNN/Transformer 感知模块协同工作，同时保留决策级别的可追溯性。结果：在 500 次仓库机器人导航模拟决策周期中，TRACE 实现了 98.6% 的证据可追溯性、99.0% 的时间连续性和 98.1% 的决策可重建性，在重建能力上优于 LIME 等事后解释方法。

Paper5. User Feedback Provides a Unique Signal that LLMs Can not Detect
2026-09-03 01:42 Beijing | https://arxiv.org/abs/2609.02859v1
Problem: User feedback from real interactions is widely believed to be a noisy, hard-to-use learning signal for LLMs. Approach: The authors construct synthetic data with definitive ground truth plus naturalistic data, then compare model revisions made with vs. without access to user feedback. Result: Feedback-informed revisions fix targeted issues at significantly higher rates than baseline revisions, but LLM judges systematically fail to recognize responses that were correctly fixed via feedback, exposing a bias in current evaluation methods rather than a real weakness of feedback itself.
问题：普遍认为，来自真实交互的用户反馈对 LLM 来说是一种嘈杂、难以利用的学习信号。方法：作者构造了带有明确真值的合成数据以及自然场景数据，比较有无用户反馈参与时模型修订结果的差异。结果：有反馈参与的修订，修复目标问题的成功率显著高于基线修订；但 LLM 评审模型系统性地无法识别出那些确实是靠反馈才修正成功的回复，说明问题出在现有评测方法的偏差上，而非反馈信号本身没用。

Paper6. The Implications of Linguistic Illegibility for LLM Security
2026-09-03 01:37 Beijing | https://arxiv.org/abs/2609.02852v1
Problem: Security mechanisms like chain-of-thought monitoring and constitutional self-critique assume an LLM's language output reliably reflects its internal computation, but this may not hold.
